# GAME OF CAT: War of the Nine Lives

A playable browser strategy/tactics prototype for Chapter I, **The Missing Seal** (working title). Character names and story roles are provisional unless explicitly described as verified. Supplied images in `docs/references/` are the visual source of truth.

## Run locally

```powershell
npm.cmd install
npm.cmd run dev
```

Open `http://localhost:4173`.

## Checks

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
```

The chapter supports kingdom actions, council rulings, scouting and army movement, a pausable tactical battle, retreat, Rally, evidence persistence, nine-life rewinds, autosave, export/import, and two survival routes.
